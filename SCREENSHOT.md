# Screenshot Keybindings

All screenshots copy to clipboard by default. Add **Shift** to save to `~/Pictures` instead.

| Key | What it captures |
|-----|-----------------|
| `Print` | Both monitors |
| `Ctrl + Print` | Region (draw a box) — external keyboard |
| `fn + F10` | Region (draw a box) — internal keyboard |
| `Super + Print` | Current monitor |
| `Super + Ctrl + Print` | Active window |
